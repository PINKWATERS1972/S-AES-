## 3. 上传GitHub/Gitee

首次使用GitHub可先阅读 [逐步上传教程](GitHub上传教程.md)，按当前项目的实际目录操作。

1. 登录个人账号，新建课程仓库，例如s-aes-homework，按课程需要设置可见性。
2. 在仓库选择“Add file → Upload files”，上传本项目三个目录、README.md、两个启动脚本和.gitignore，保持子目录结构。
3. 忽略__pycache__、*.pyc等缓存，不需要上传临时文件或本机Python环境。
4. 提交文件后，检查首页README可读、五关链接可打开、图片可显示、源码与指南齐全。
5. 若他人需要运行，下载完整项目并解压，通过根目录启动脚本或文档命令运行；只下载main.py无法正常复用。

Markdown无须转PDF。README自动出现在仓库首页，其他.md点击后显示排版；图片与报告必须一起上传，重命名图片后同步修改链接。不能只上传电脑D盘路径。
