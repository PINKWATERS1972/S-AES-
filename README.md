# S-AES 算法实验室

《信息安全导论》课程作业：以 Python 和 Tkinter 实现 16 位 S-AES，从单分组运算逐步扩展到字符消息、多重加密、密钥恢复与 CBC 错误传播。

**环境**：Python 3.10+（需含 Tkinter） · **依赖**：仅标准库 · **记录状态**：20 项自动测试通过，四个关卡已有完整界面证据，组间互测待补充。

![基础加密界面](02_测试结果/第1关_基础加解密/01_基础加密.png)

## 开始使用

Windows 双击本目录的 **[启动程序.bat](启动程序.bat)**。本机脚本优先使用 D:\anaconda3\python.exe，无需安装第三方包。
进入窗口后，按顶部页签选择实验。详细输入、按钮操作和结果解释见 [用户指南](03_相关文档/用户指南.md)。

在项目根目录也可运行：

```powershell
python .\01_源代码\main.py
```

需要重新验证算法时，双击 **[运行测试.bat](运行测试.bat)**；输出更新到 `02_测试结果` 中的日志和自动测试摘要，已整理的图文实验记录会保留。

## 5.2.1 源代码

| 入口 | 负责内容 |
|---|---|
| [saes.py](01_源代码/saes.py) | 单分组、密钥扩展、ASCII、双重/三重、MITM 和 CBC |
| [main.py](01_源代码/main.py) | 桌面输入、逐轮显示、文件交换、后台攻击与差分对比 |
| [experiment_io.py](01_源代码/experiment_io.py) | JSON结构校验、向量生成与比较、攻击输入行号定位 |
| [算法测试](01_源代码/tests/test_saes.py) / [交换测试](01_源代码/tests/test_experiment_io.py) | 共20项断言测试，含完整明文空间、轨迹及导入契约 |
| [verify.py](01_源代码/verify.py) | 测试运行、数据导出与摘要更新 |
| [示例向量](01_源代码/examples/cross_vectors.json) / [攻击数据](01_源代码/examples/attack_pairs.txt) | 可复现、可交换的实验输入 |

核心接口使用16位整数，GUI负责交互，experiment_io负责实验数据校验；两者均可独立于窗口调用。输入或模式变化后，程序会撤下旧结果并提示重算；攻击运行期间锁定输入，避免混用参数。基础页现在也提供逐步解密过程。
